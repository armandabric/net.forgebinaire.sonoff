Sonoff Hydro adds support for the Sonoff Hydro One Zigbee smart water valve in Homey: models SWV-ZFU, SWV-ZFE, SWV-ZNU and SWV-ZNE. It provides on/off control, leak and water-shortage alarms, child lock status, battery level, and the duration and volume of the last watering run. Two Flow actions let you open the valve for a set duration or a set amount of water; the volume action requires the flow meter built into SWV-ZFU/SWV-ZFE.

The valve communicates over Zigbee directly with Homey, with no cloud account or companion app involved. Scheduling watering runs is handled through Homey's own Flow system.

The Sonoff Hydro DUO (SWV-ZF2E, SWV-ZF2U) is a different product and is not supported by this app.
