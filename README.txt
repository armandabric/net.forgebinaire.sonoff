Sonoff Hydro adds support for the Sonoff Hydro One Zigbee smart water valve in Homey. It provides on/off control, leak and water-shortage alarms, child lock status, battery level, and the duration and volume of the last watering run. Two Flow actions let you open the valve for a set duration or a set amount of water.

The valve communicates over Zigbee directly with Homey, with no cloud account or companion app involved. Scheduling watering runs is handled through Homey's own Flow system.
